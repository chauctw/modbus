# Project Context Rule
"Do not output your thinking process, chain of thought, or use <think> tags. Provide only the final code and a brief explanation."
Always read `README.md` first before making any code changes. Use the README's module grouping and data flow sections to identify exactly which files are relevant to the requested change. Do not read the entire project — only open files that are directly related to the task at hand. This prevents unintended side effects on unrelated modules.
